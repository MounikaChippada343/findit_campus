# FindIt Campus — Smart Lost and Found Management System

FindIt Campus is a cross-platform mobile application designed to help college students and staff efficiently report lost belongings, discover found items, submit ownership claims, and coordinate item returns.

## Features
- **Secure Authentication**: Email/password registration and login with role segregation.
- **Item Reporting**: Detailed lost/found reporting with image picking and Firebase Storage.
- **Advanced Search & Discovery**: Filter by category, status (Lost/Found), and campus building.
- **Ownership Claim Workflow**: Secure claim submissions, status tracking, and owner moderation.
